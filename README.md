## 🌐 Cómo subirlo a GitHub (PARA PRINCIPIANTES)

### Opción 1: La más fácil (sin comandos, solo navegador) - 3 minutos

1. Ve a https://github.com y crea cuenta gratis si no tienes
2. Click en el botón verde **"New"** o **"+" > New repository**
3. Ponle nombre: `mis-juegos-supervivencia`
4. Marca **"Add a README file"** y dale **Create repository**
5. Dentro de tu repo, click en **"Add file" > "Upload files"**
6. Arrastra TODA la carpeta `survival-pack-github` que te di (todos los html y carpetas)
7. Espera a que suba y dale **Commit changes**
8. Ve a **Settings > Pages** (en el menú de la izquierda)
9. En **Source**, selecciona **"Deploy from a branch"**, Branch: **main**, Folder: **/ (root)** y **Save**
10. ¡Listo! En 1 minuto tendrás tu link: `https://TU_USUARIO.github.io/mis-juegos-supervivencia/`

### Opción 2: Con GitHub Desktop (aún más fácil)

1. Descarga GitHub Desktop: https://desktop.github.com/
2. Instala e inicia sesión
3. File > New Repository > nombre: `mis-juegos-supervivencia`
4. Copia todos mis archivos dentro de la carpeta que te crea
5. En GitHub Desktop verás los cambios, escribe "primer commit" abajo y dale **Commit to main**
6. Luego **Publish repository** (publicar)
7. Activa GitHub Pages como en el paso 8 de arriba
