# NEON STRIKE

> A high-intensity browser shooter built for fast reflexes, clean combat, and endless survival.

[![Play Now](https://img.shields.io/badge/PLAY%20NOW-Live%20Demo-47f4ff?style=for-the-badge)](https://dev-piyushrawat.github.io/neon-strike/)
[![Built With](https://img.shields.io/badge/Built%20with-HTML%20%7C%20CSS%20%7C%20JavaScript-ff3b81?style=for-the-badge)](#tech-stack)

**NEON STRIKE** is a sleek, arcade-inspired top-down survival shooter. Enter a neon-lit arena, outmaneuver increasingly aggressive hostiles, unlock temporary weapon overdrive, and push for the highest score.

## Live Demo

Play it here: **[dev-piyushrawat.github.io/neon-strike](https://dev-piyushrawat.github.io/neon-strike/)**

## Features

- Fast, responsive top-down combat
- Mouse-based aiming and rapid-fire pulse rifle
- Dash mechanic with energy management and brief invulnerability
- Progressive enemy waves and elite enemy variants
- Score system, combo multiplier, wave counter, and persistent best score
- Collectible health repairs and tri-shot weapon overdrive
- Pause, restart, and game-over states
- Smooth particle effects, dynamic glow, screen shake, and custom canvas rendering
- Responsive neon HUD designed for desktop and mobile-sized displays
- Zero build tools or frameworks required

## Controls

| Key / Input | Action |
| --- | --- |
| `W` `A` `S` `D` | Move |
| Mouse | Aim |
| Left click / hold | Fire |
| `Space` | Dash |
| `P` or `Esc` | Pause / resume |

## Run Locally

No installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/dev-piyushrawat/neon-strike.git
   ```

2. Open the project folder.

3. Double-click `index.html`, or open it with your browser.

For development, you can also use a local server extension such as VS Code Live Server.

## Project Structure

## Tech Stack

- **HTML5 Canvas** — arena rendering, combat effects, and game loop
- **Vanilla JavaScript** — movement, combat, collisions, waves, and scoring
- **Modern CSS** — responsive HUD, overlays, visual effects, and animation

## Deploy Your Own Copy

This project is ready for GitHub Pages:

1. Fork this repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder.
5. Save. GitHub will provide a public game URL.
